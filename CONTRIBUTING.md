# Contributing

Contributions are welcome, especially compatibility fixes for newer BT Panel / aaPanel and Google Drive plugin versions.

Please:

1. avoid committing vendor plugin source or credentials;
2. keep patch matching narrow and fail-safe;
3. add/update compatibility notes;
4. never use a global replacement of `bt_backup` in shared panel core files;
5. include a sanitized diagnostic example when fixing version-specific issues.
