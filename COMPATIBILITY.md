# Compatibility

| Component | Status |
|---|---|
| Google Drive plugin 2.5 | Designed / tested target |
| Default `/www/server/panel/` layout | Supported |
| Multiple servers, one Drive account | Supported |
| Dynamic public IPv4 directory | Supported |
| IPv6-only server naming | Not currently supported |
| Future plugin versions | Unknown; fail-safe checks are used |

The project deliberately avoids claiming compatibility with versions that have not been tested.
