# v0.1.0 Release Notes

Initial public release of `bt-gdrive-multiserver-backup`.

Highlights:

- one shared `BT-Backup` root for multiple servers;
- public IPv4 based server subfolders;
- parent-aware Google Drive folder resolution;
- safe backups and rollback before modifying panel files;
- one-command repair after panel/plugin upgrades;
- redacted diagnostics;
- no bundled vendor source, credentials, OAuth tokens, or personal Folder IDs.

Before installing, read `README.md` / `README.zh-CN.md` and `SECURITY.md`.
